# Política de Privacidade / Privacy Policy - Status Bot

Este aplicativo ("Status Bot") é uma ferramenta de uso pessoal e automatizado para sincronização de vídeos próprios armazenados no Google Drive do proprietário para publicação nos status do WhatsApp.

## 1. Coleta e Uso de Dados
- O aplicativo acessa exclusivamente os arquivos de vídeo armazenados na pasta configurada pelo usuário no Google Drive.
- Não coletamos, compartilhamos nem vendemos informações pessoais, dados de terceiros ou credenciais a ninguém.
- Os tokens de acesso (OAuth) são armazenados localmente e de forma segura pelo próprio usuário em seu servidor privado.

## 2. Permissões do Google
- O escopo de acesso ao Google Drive é utilizado estritamente para download de vídeos designados pelo usuário para postagem.
